# Fonts

`BricolageGrotesque-ExtraBold.ttf` is Bricolage Grotesque, weight 800, from Google Fonts
(https://fonts.google.com/specimen/Bricolage+Grotesque). It is licensed under the SIL Open Font
License 1.1 (https://openfontlicense.org). It is used only to render the social preview image
(`app/opengraph-image.tsx`); the site itself loads the same family through `next/font`.
